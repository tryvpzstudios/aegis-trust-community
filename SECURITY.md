# Security and Responsible Disclosure

This public community repository is for safe, non-sensitive collaboration. It is not authorization to test AEGIS TRUST infrastructure, accounts, repositories, deployments, third-party services or real users.

## Do not
- Test, scan, exploit or access systems without explicit written authorization and defined scope.
- Publish vulnerabilities, exploit details, credentials, tokens, private keys or personal data in public issues.
- Upload real evidence, customer/victim data or sensitive datasets.
- Attempt account takeover, social engineering, denial of service, data extraction or destructive testing.

## Reporting
Do not open a public issue with sensitive vulnerability details. Use GitHub's private vulnerability reporting feature if enabled, or ask the maintainer for a private reporting channel without posting details.

A report should include a concise description, affected component/version, safe reproduction summary, impact and suggested remediation. Never include secrets in public communications.

A report is not confirmed until independently reviewed. Acknowledgement, triage and remediation timelines are not guaranteed. Never assume authorization from this page.
