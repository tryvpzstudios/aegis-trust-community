# AEGIS TRUST — Developer & Researcher Recruitment

🌍 **Global contributors welcome**

We are building AEGIS TRUST, a global digital trust infrastructure initiative exploring digital evidence, provenance, identity protection, product verification, media integrity and responsible AI.

We welcome:
- Software developers and API engineers
- Security and privacy researchers
- AI/ML engineers and evaluators
- QA and test engineers
- UX/UI and accessibility contributors
- Technical writers and documentation contributors
- Researchers and Malayalam/localization contributors
- Students and independent innovators

## Starter tasks
Choose a public task in our GitHub Issues:
https://github.com/tryvpzstudios/aegis-trust-community/issues

Beginner-friendly tasks currently include accessibility review, evidence/provenance glossary, synthetic test scenarios, onboarding documentation and Malayalam localization.

## How to join
1. Visit the community repository.
2. Read README and CONTRIBUTING.
3. Pick a task or open an issue proposing your contribution.
4. Wait for maintainer acceptance before substantial work.
5. Submit a pull request for review.

## Collaboration principles
Evidence-first, privacy-by-design, safe and scoped work, respectful global collaboration, transparent contribution attribution and honest reporting.

This is an open community initiative—not a job advertisement. No salary, employment, equity, prize or revenue-share is promised. Any paid, commercial, confidential or IP-sensitive work requires a separate written agreement before it begins. Private core code, credentials, customer data and sensitive IP are not part of public tasks.
