# AEGIS TRUST — 10-Day Execution Board
**Mission:** Maximum-speed build, test, deploy, and global launch attempt within 10 days. Execution target, not a claim that every component will be production-certified.

## Execution rules
- Build existing assets forward; do not restart planning.
- Parallelize independent tracks.
- Each deliverable requires a test/verification record.
- Synthetic/public data only in this repository.
- Never publish secrets, private evidence, customer data, or patent-sensitive implementation.
- A hash is not authenticity; verification results must state scope and limitations.
- Security/privacy gates remain mandatory.

## Tracks
A. Browser verifier and provenance inspection
B. Evidence schema, synthetic datasets, challenge arena
C. API, public records, monetization research/implementation
D. Mobile-first landing page, bilingual UX, distribution/community
E. CI, automated testing, security audit
